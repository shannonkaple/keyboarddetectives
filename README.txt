

V7.4 SAFE SAVE / NO ACCIDENTAL RESTART
- RESET GAME is now protected by a full-screen confirmation.
- Students must deliberately choose YES — START OVER before ANY saved progress is erased.
- NO — KEEP MY PROGRESS is the safe/default choice.
- Completing a case does NOT reset progress.
- Completing all bonus missions does NOT reset progress.
- Final completion is saved BEFORE the Epic Secret Agent celebration appears.
- After full completion, the permanent displayed rank changes to EPIC SECRET AGENT.
- Case completion and final celebration explicitly display PROGRESS SAVED.
- Added a browser-side backup snapshot of:
  • points
  • solved cases
  • case scores
  • briefcase collection
  • bonus mission completion
  • Epic Agent achievement
- If primary save data is unexpectedly empty but the backup contains real progress, the page restores it automatically.
- Intentional RESET GAME also deletes the backup, so a confirmed reset still works correctly.
- Refreshing/reopening the page does not intentionally clear anything.
