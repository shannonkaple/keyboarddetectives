MS. KAPLE'S KEYBOARD DETECTIVE AGENCY

A GitHub-ready, one-file keyboard game for first grade.

8 CASES
1. The Missing Letter
2. Capital Clue
3. First-Letter File
4. Number Hunt
5. Count the Evidence
6. Before & After
7. Letter Code Breaker
8. Number Code Breaker

SKILLS
- Letters only
- Numbers 0-9 only
- Uses the actual keyboard
- Each case has 10 clues
- Scores save in the browser if students leave a case and come back
- Auto-fits to different student computer screen sizes

GITHUB
Upload index.html to the root of your GitHub Pages repository.
That is the entire game. No asset folder is required.
